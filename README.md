# React Practice

A collection of small projects and exercises for learning React, from JSX and components to hooks and forms.

## Lessons

| Directory | Topics |
| --- | --- |
| `L1ReactIntro` | React introduction |
| `L2Jsx,componet,props,babel` | JSX, components, props, and Babel |
| `L3setup` | Project setup |
| `L4Hook` | React hooks |
| `L5HookEffect` | Effects with `useEffect` |
| `L6.1Theory` | React concepts and theory |
| `L6.2` | React practice |
| `L7useMemo _useCallbackHook` | `useMemo` and `useCallback` |
| `L8useRef` | `useRef` |
| `L9HookForm` | Forms and hooks |
| `L10` | React practice |
| `vite-project` | Vite-based React project |

## Getting started

Each lesson folder may be a separate project. Open the folder you want to explore, install its dependencies, and run the available scripts from that folder. For a typical Vite project:

```bash
cd vite-project
npm install
npm run dev
```

Check the folder's `package.json` for its scripts and any project-specific instructions.

## Purpose

This repository is for personal learning and practice with React. Examples and project structure may evolve as new topics are explored.
